    How the rules work

    Aircraft-side pattern. At least 2 different units came off the same aircraft slot in the last 12 months with the same fault code, and the shop found nothing wrong each time. A confirmed unit failure at that slot lowers how sure we are, because a real fault could explain it.

    Unit-side pattern. The same unit came off at least 2 different aircraft with the same fault code, and the shop found nothing wrong each time. For units we look at their whole history, not just 12 months, because units can sit on the spares shelf for months between installs. (Our synthetic fleet test showed this catches about twice as many problem units.)

    How sure depends on how many repeats point the same way. How urgent is separate: how serious the system is × how often the fault has come back. A strong pattern on cabin equipment can be less urgent than a weak one on navigation.

    AvioTrace never removes or releases anything by itself. It shows the pattern and the records; a qualified person decides.

    Words used here
    Unit
    A replaceable box of electronics (an "LRU"), e.g. a navigation computer. Each has a serial number.
    Slot
    The place on a specific aircraft where a unit is installed, e.g. N804AT, left slot.
    No fault found (NFF)
    The unit was removed for a fault, but the repair shop's test found nothing wrong.
    Fault code
    The code recorded with the fault, used here to tell whether faults look like the same problem.
    Shop test
    The standard bench test a unit gets after removal. It runs on the ground, so it may not recreate flight conditions.
    Self-test (BITE)
    The unit's built-in check of itself.
    Aircraft side
    Everything around the unit that stays with the aircraft: wiring, connectors, power, and signals from other systems.
